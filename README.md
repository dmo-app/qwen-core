# Core

DAW desktop leve e fiável, centrado em plugins externos e áudio importado/gravado. Windows 11 x64 é P0; uso privado, local-only, sem subscrição.

**Camada criativa: Pattern Maker + Tools.** Manter catálogo de padrões e alinhamento kick/baixo/pratos. Explorar painéis simples de Tools com acesso directo ao editor de cada plugin da chain. Retirar instrumentos/designers próprios, módulos antigos e samples distribuídos. VST3 é o suporte auditado, não o limite futuro do produto.

**AI fora por agora.** A integração actual ainda tem desvios; a decisão de a separar não significa implementação concluída.
